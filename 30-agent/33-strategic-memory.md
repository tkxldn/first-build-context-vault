# strategic-memory.md — Durable Decisions and Standing Truths

---

## What This File Is

Every working relationship develops shared understanding over time — decisions that have been made, patterns that have been identified, directions that have been chosen. Without a place to record them, an agent re-litigates closed questions, repeats resolved mistakes, and loses the accumulated intelligence built session by session.

This file is that place.

It is not a task list. It is not a session log. Those belong elsewhere.

This is a registry of things that are now standing truth — decisions your agent should treat as settled, insights that should change how it operates, and directions that rule out certain alternatives. When your agent reads this file, it knows what is already decided and can focus entirely on what is still open.

---

## How to Use This File

Unlike the other files in this vault, this one is not built in a single interview session. It starts empty and grows naturally as you work with your agent.

**When to add an entry:**

At the end of any working session, ask yourself: *did anything happen today that a future agent should treat as standing truth — not just a task to complete?*

If yes, open this file and add a new entry. It takes two minutes.

**What qualifies:**
- A decision that should not be re-opened or re-litigated
- A pattern you have recognised in how you work that the agent should account for
- A direction that was considered and consciously set aside
- Something you tried that definitively did not work
- A standing preference or rule that emerged from experience

**What does not qualify:**
- Tasks to do (those go in your handoff or task list)
- Session notes or summaries
- Information that belongs in another context file (personal details go in `01-me/`, household logistics in `02-family/`, etc.)

---

## How to Write an Entry

Keep entries short. An agent needs to be able to read this file quickly and act on it.

**Format:**

```
**[YYYY-MM-DD] — [Short descriptive title]**
What was decided or learned. Why it matters. What it means for how the agent should operate going forward. Specific enough that a new agent reading this in six months understands exactly what is settled and why.
```

**Good entry:** specific, actionable, explains the why.
**Bad entry:** vague, no context, no standing instruction.

Example of a good entry:
```
**2026-04-20 — Long-form proposals are off the table**
After sending two proposals over four pages, both were not read in full by the client. 
Agreed: all proposals are a maximum of two pages. Credentials section removed. 
Agent should never suggest or produce a proposal longer than two pages without explicit instruction.
```

---

## How to Add an Entry With AI Help

You can use your AI agent to help you write entries. At the end of any session, say:

> "What happened today that I should record in my strategic memory? Help me write an entry for anything we decided or learned that should be treated as standing truth going forward."

The agent will identify candidates and draft entries for your review.
